# JOJX Home v2

Design export from Claude Design. Open `index.html` in a browser, or publish it with GitHub Pages so the team gets a link.

## Put it on GitHub in about two minutes

1. Go to github.com, click **New repository**, name it `jojx-site-v2`, keep it **Private**, click Create.
2. On the empty repo page click **uploading an existing file**, drag `index.html` and this `README.md` in, click **Commit changes**.
3. In the repo go to **Settings → Pages**, under *Build and deployment* set Source to **Deploy from a branch**, Branch **main** / root, Save.
4. After a minute the Pages section shows the link, something like `https://<your-username>.github.io/jojx-site-v2/`. Send that to the team.

Private repos need GitHub Pro (or a Team/Enterprise org) for Pages. On a free account, make the repo Public or share the `index.html` file directly, it opens fine locally.
